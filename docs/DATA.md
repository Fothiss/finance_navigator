## Детали по методам ЦБ (SOAP)

`POST http://www.cbr.ru/DailyInfoWebServ/DailyInfo.asmx`, заголовок `SOAPAction: "http://web.cbr.ru/<Метод>"`,
тело — `<Метод xmlns="http://web.cbr.ru/">` с элементами `<fromDate>` (нижний `f`) и `<ToDate>`.
Ошибка в имени параметра не даёт ошибку: сервис возвращает пустой результат.

- `KeyRateXML` → `<KR><DT>2026-11-11T00:00:00+03:00</DT><Rate>16.00</Rate></KR>`
- `RuoniaXML` → `<ro><D0>2026-11-10T00:00:00+03:00</D0><ruo>15.7700</ruo><vol>757.7700</vol></ro>`
- `ROISfixXML` → всегда `<ROISfix xmlns="" />` (метод жив, данных нет с 03.2022)

## Кривая бескупонной доходности ОФЗ (КБД)

`POST https://www.cbr.ru/hd_base/zcyc_params/` с полями `UniDbQuery.Posted=True`,
`UniDbQuery.From=DD.MM.YYYY`, `UniDbQuery.To=DD.MM.YYYY`. Ответ — HTML-таблица:
строка = дата + значения по теноровой сетке (0.25 / 0.5 / 0.75 / 1 / 2 / 3 / 5 / 7 лет), десятичная
запятая. В части исторических периодов число колонок меньше, чем теноров в заголовке, поэтому
парсер обязан сопоставлять значения с тенором по позиции из заголовка, а не жёстким индексом.

## RUSFAR1M (MOEX ISS)

`GET https://iss.moex.com/iss/history/engines/stock/markets/index/securities/RUSFAR1M.json`
с параметрами `from`, `till`, `start` (пагинация по 100 строк), `iss.meta=off`,
`history.columns=TRADEDATE,CLOSE`. Значение `CLOSE` — ставка в процентах годовых; на 11.11.2026
равна 14.01 при ключевой ставке 14.00, то есть премия рынка к ключевой практически нулевая и
согласуется с кривой ОФЗ (1Y = 14.00).

## Что это значит для модуля 1

1. Терминальной структуры МБК (ROISfix/MOSPRIME/MIACR) нет — прежний замысел «спред терм-фиксингов»
   заменён на премию за срок из RUSFAR1M и кривой ОФЗ к ключевой ставке.
2. Общий период двух индикаторов — 2019-04 … наст. вр. (~7.5 лет, ~90 месячных наблюдений) —
   достаточно для бэктеста правила при `min_observations = 30`.
3. Ключевая ставка нужна и как база премии, и как таргет («повышение за 30 дней»).
4. Ставка МСП используется только как бенчмарк надбавки, поэтому её короткая история (01.2024+)
   не ограничивает сигнал.
