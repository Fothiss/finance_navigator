# Финансовый навигатор

Веб-приложение для финансовых директоров и владельцев среднего бизнеса,
которое помогает принимать решения о деньгах **до того**, как изменения
на рынке превращаются в дорогие кредиты, кассовые разрывы и налоговые
сюрпризы.

## Проблема

Финдиректор среднего бизнеса видит ключевую ставку в новостях, курс валют
в терминале и налоговые платежи постфактум. Но он не понимает:

- Когда реально идти в банк за кредитом (ключевая ставка — не цена кредита).
- Насколько его валютная позиция уязвима к резкому движению курса.
- Сколько налогов придётся заплатить в следующем месяце — до того, как
  данные по выручке появятся.

Существующие решения — либо терминалы для трейдеров (SberCIB, Bloomberg)
за большие деньги, либо витрины готовых кредитных продуктов (МСП.РФ,
Банки.ру), которые не предупреждают о рисках, либо бухгалтерские сервисы
(«Контур.Экстерн»), которые считают налоги постфактум, когда данные уже
есть. Ниша между ними — пустая.

## Что делает приложение

Три аналитических модуля:

### Модуль 1. «Стоимость денег»
Считает спред между рыночными ставками межбанковского рынка
(RUONIA, ROISfix) и ключевой ставкой ЦБ. Растущий спред — опережающий
сигнал того, что банки скоро поднимут ставки по кредитам для бизнеса.
Пользователь получает вердикт на языке бизнеса, а не таблицу индикаторов.
ML-слой оценивает вероятность роста ставок по кредитам МСП в ближайшие
недели.

### Модуль 2. «Валютный риск»
Считает волатильность валютной корзины и цен на золото, детектирует
аномальные дни и синхронность движений. Пользователь получает оценку
вероятности резкого движения курса и — с учётом своей валютной позиции —
оценку того, как это отразится на его марже. ML-слой оценивает вероятность
аномального движения на основе текущей волатильности и корреляций.

### Модуль 3. «Налоговый прогноз»
Прогнозирует выручку и расходы предприятия на следующий месяц на основе
загруженной истории транзакций, а затем считает налоги (НДС, страховые
взносы, налог на прибыль или УСН) на основе этого прогноза. Пользователь
видит не «сколько налогов было», а «сколько налогов будет» — и может
заранее скорректировать планы.

**Важно:** модель прогнозирует не налоги, а базу (выручку и расходы).
Налоги считаются арифметикой после — это честная и защищаемая постановка.

## Для кого

Средний бизнес (не микробизнес и не крупные компании с казначействами):

- **Бизнес с кредитной нагрузкой или планами на заём** — модуль 1.
- **Бизнес с валютной выручкой или закупками** — модуль 2.
- **Любой бизнес, которому нужно планировать налоги** — модуль 3.

Не для: микробизнеса без кредитов, без валюты и без налогового
планирования (им это не нужно), крупных компаний с собственными
казначействами (у них есть терминалы).

## Источники данных

**Внешние (модули 1 и 2):**
- API Банка России (официальный, бесплатный, без регистрации юрлица):
  ключевая ставка, RUONIA, ROISfix, курсы валют, цены на золото.
- Средневзвешенные ставки по кредитам МСП (ЦБ, помесячно) — для
  сравнения ставки пользователя со средней по отрасли и региону.

**Внутренние (модуль 3):**
- CSV/Excel с транзакциями пользователя (выписка или выгрузка из 1С).
- Агрегация до месячного уровня: выручка + 3–5 категорий расходов
  (закупки, ФОТ, аренда, логистика, прочее).

## Технологии

- **Backend**: Python, FastAPI, PostgreSQL, Redis (кеш данных ЦБ).
- **ML-слой**:
  - Модули 1 и 2: классификаторы вероятности события (baseline —
    логистическая регрессия, основная модель — градиентный бустинг).
  - Модуль 3: прогноз временных рядов (baseline — наивный прогноз
    «прошлый месяц», основная модель — Prophet; опционально XGBoost
    на лаговых признаках).
- **Frontend**: React или HTMX (MVP — HTMX для скорости).
- **Фоновые задачи**: ARQ или Celery для ежедневной выгрузки данных ЦБ.

## Ключевые принципы

- **Не прогнозируем точечно.** Не «курс будет 95», а «вероятность резкого
  движения повышена». Не «налог будет ровно 123 456 рублей», а «прогноз
  с интервалом 80%». Это честно и защищаемо.
- **Всегда есть baseline.** Любая ML-модель сравнивается с простым правилом
  или наивным прогнозом — на защите показываем прирост.
- **Бэктест обязателен.** Сигнал проверяется на истории: после высокого
  спреда ставки МСП действительно росли чаще? Прогноз выручки действительно
  лучше наивного?
- **Кешируем данные ЦБ.** Пользователь не ждёт ответа ЦБ в реальном времени.
- **Не все модули обязательны для всех.** Пользователь подключает те,
  которые решают его боль.

## Быстрый старт

### Backend

`uv` и все зависимости уже лежат внутри `backend\.venv`, поэтому работать можно без глобальной установки:

```powershell
cd backend
.\.venv\Scripts\uv.exe run python app\__main__.py   # http://127.0.0.1:8000, Swagger на /docs
.\.venv\Scripts\uv.exe run python -m app.data.sync  # обновить снапшоты данных ЦБ/MOEX
.\.venv\Scripts\uv.exe run pytest -v
.\.venv\Scripts\uv.exe run ruff check .
.\.venv\Scripts\uv.exe sync                         # доустановить зависимости
```

Без `uv` вообще тоже работает — интерпретатор и пакеты в том же venv:

```powershell
cd backend
.\.venv\Scripts\python.exe app\__main__.py
.\.venv\Scripts\python.exe -m pytest -v
```

Если поставишь `uv` глобально (`py -m pip install --user uv`), команды сокращаются до обычных
`uv run ...` из каталога `backend`. Базовый интерпретатор — `%LOCALAPPDATA%\Programs\Python\Python312`
(команда `python` в PATH может быть перекрыта заглушкой Microsoft Store; тогда используй `py`).

### Frontend

```bash
cd frontend
npm install --ignore-scripts   # --ignore-scripts: esbuild не требует postinstall
npm run gen:api                # типы из http://127.0.0.1:8000/openapi.json (backend запущен)
npm run dev                    # http://localhost:5173, прокси /api на 127.0.0.1:8000
npm run build
npm run lint
npm run test
```

### Docker

```bash
docker compose up -d --build
curl http://127.0.0.1:8000/api/v1/health
```

## Модуль 1: что считается

Два независимых сигнала о вероятности повышения ключевой ставки в ближайшие 30 дней:

- `rusfar_term_premium` — премия RUSFAR 1M к ключевой ставке (MOEX ISS);
- `ofz_curve_premium` — премия кривой ОФЗ 1 год к ключевой ставке (ЦБ, КБД).

Вероятность — условная частота события на месячной сетке с интервалом Уилсона 80%, рядом всегда
baseline (безусловная частота). Варианты сравниваются по Brier (`comparison`). Ставка МСП
используется только как бенчмарк надбавки, а не как цель прогноза.

Контракты: [docs/API.md](docs/API.md). Источники и глубина истории: [docs/DATA.md](docs/DATA.md).
