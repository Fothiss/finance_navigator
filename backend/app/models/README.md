# app/models

Модуль 1 «Стоимость денег» не хранит пользовательских данных: всё выводимо из публичных выгрузок
Банка России, а кеш живёт в `app/data/cache.py` (TTL + JSON-снапшот).

Поэтому таблиц и SQLAlchemy-моделей здесь нет. Пакет остаётся в дереве, чтобы структура совпадала
с AGENTS.md.

БД появится в change'ах для модуля 3 (транзакции пользователя) и профиля (история сигналов).
